# PolyPalette

Hey all, this is where you download PolyPalette. It's a surfacing and modelling suite for 3ds Max and Blender.

It's alpha software, so expect a few rough edges.

- Buy a licence: https://jevzza.gumroad.com/l/PolyPalette
- Latest release: https://github.com/Jevzza/PolyPalette_Releases/releases/latest
- Discord: https://discord.gg/aPES2GVXtE
- Wiki: https://github.com/Jevzza/PolyPalette_Releases/wiki
- Blender plugin: https://github.com/Jevzza/PolyPalette_Releases_Blender

## Try it first

There's a 14 day trial with every module unlocked. You don't need to give payment details, and you don't need 3ds Max or Blender connected to start it.

The trial clock starts when you install, not when you first open it. Install it when you've got a project to test it on.

## What you need

- Windows 10 or 11
- 3ds Max 2024 or newer, or Blender 4.2 LTS or newer
- An internet connection

## Installing

There are 2 pieces. The PolyPalette app, and a plugin for each copy of 3ds Max or Blender you use. The app installs the plugins for you.

1. Download `PolyPalette-Installer-<version>.exe` from the [latest release](https://github.com/Jevzza/PolyPalette_Releases/releases/latest) and run it.
2. Open PolyPalette. On the About tab press Start Trial, or paste in your licence key and press Activate.
3. Open the Connection tab, find your version of 3ds Max or Blender and press Install Plugin.
4. If that app was already open, restart it.
5. Press Launch on its tile. Once it's running, the tile turns into Connect.

The app's name and status turn green once it's connected. After that it connects on its own whenever PolyPalette is open.

## Installing the 3ds Max plugin by hand

You only need this if Install Plugin can't do it. Download the zip for your version from the latest release. 2024 has its own, 2025 and 2026 share one, and 2027 has its own. Unzip it, then:

1. Start 3ds Max.
2. Drag `PolyPalette_Max_Install.ms` from the `install` folder into the viewport.
3. Restart 3ds Max.

## Updating

On the About tab, press Check for Updates. Turn on Auto-Update and it keeps PolyPalette and your plugins current for you.

Your licence doesn't expire. Maintenance is what covers new versions, and renewing it is optional. If it runs out, the version you've got keeps working.

## Help

Bugs go in the bugs channel on the Discord. Say which version you're on (bottom right of the window), what you did and what you expected. If a report card popped up, press Copy on it and paste the lot.

The wiki covers connection problems, licensing and every tool.
